# Case in Your Room

A one-player murder mystery for Specs. A crime scene is laid over the player's room. The player walks around, inspects the clues, then names the culprit among 3 suspects. A correct answer replays the culprit's path through the room and shows the truth.

Made with Lens Studio 5.24.1 for the Devpost hackathon "Learn AR with SPECS".

Built with the help of AI tools (Claude Code and CLAD); every text was checked by a person.

## Open the project

1. Install [Git LFS](https://git-lfs.com/) before cloning. Files under `Assets/` and `Packages/` are stored with Git LFS.
2. Clone this repository and open `specs-lens.esproj` in Lens Studio.

## What's inside

- `Assets/Scripts/`: the game scripts (TypeScript)
- `Assets/Tests/`: LEAF test scenarios
- `devpost/design-brief.md`: the design brief the Lens was built from
- `THIRD_PARTY_NOTICES.md`: licenses of the icons, packages and other files that come from third parties
